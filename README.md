### 01 · AWS Infrastructure Automation

Infraestructura en AWS gestionada con Terraform y automatizada
mediante GitHub Actions, desde la provisión de recursos hasta
su eliminación controlada.

| Componente | Implementación |
| :--- | :--- |
| Infraestructura | Recursos definidos como código con Terraform |
| Estado remoto | Almacenamiento del estado de Terraform en Amazon S3 |
| Automatización | Workflows de GitHub Actions para `terraform apply` y `terraform destroy` |
| Acceso y credenciales | Políticas y roles IAM · GitHub Secrets |

Un proyecto para trabajar el ciclo de vida de la infraestructura
y la integración de Terraform dentro de un flujo de CI/CD.
